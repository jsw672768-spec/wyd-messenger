# 운영·비용·유지보수

유료 계약, 참가자 공개 배포, 운영 데이터 변경은 실행하지 않았습니다. 기존 호스팅 계정·도메인과 Supabase 연결을 확인할 권한이 먼저 필요합니다. 비공개 웹 검토본은 소유자 UI 검토용이며 참가자 운영 주소가 아닙니다.

## 구성과 비용

기존 Next.js를 유지할 수 있는 연결된 호스팅을 먼저 조사합니다. 별도 계정이 없다면 Next.js 서버와 Supabase를 분리하는 구성을 검토합니다. 현재 Sites 검토본은 같은 UI·보안 로직을 Worker용으로 빌드합니다. WebView는 카메라·공유·뒤로가기·네트워크 복구를 네이티브로 보완하면서 기존 기능을 공유합니다. TWA는 도메인 검증·브라우저 의존이 추가되어 APK 설치 문제를 해결하기 위해 재작성할 이유가 없습니다.

Vercel Pro + Supabase Pro 선택 시 **기본 월 약 $45부터**이며 번역·도메인·초과량·세금은 별도입니다. 계약을 체결한 것이 아닙니다. 참석자·동시 접속·공지 수×언어×글자 수와 캐시 적중률을 측정한 뒤 소유자가 승인합니다. 행사 규모에 기본 무료 번역 예산은 작으므로 예산 증액 전에 제공자 조건과 개인정보 처리를 확인합니다.

## 로그와 복구

`instrumentation.ts`는 서버 오류의 종류·제한된 지문만 구조화 로그로 남깁니다. 헤더·토큰·실제 경로·초대 ID·내용은 기록하지 않습니다. 호스팅 로그 보관·접근 통제·오류 알림 대상, 5xx·번역 실패율·응답 시간·Realtime 연결 수·용량 경보는 계정 확정 후 설정합니다. 현재 알림이 연결됐다고 주장하지 않습니다.

`/api/health`는 설정 존재만 검사합니다. 없는 경우 503, 있는 경우 200 및 `dependencies: not_probed`로 응답하므로 DB 정상 상태를 보장하지 않습니다. 합성 데이터로 별도 의존성 점검을 마련하고, 장애 시 긴급 원문 확인·현장 대체 연락 수단을 운영자가 정해야 합니다.

정기적으로 의존성/Android 보안 업데이트, CI 회귀, 백업 복원, 비용 한도와 기기 설치·업데이트를 확인합니다. 고정 커밋·스키마·서명·마지막 versionCode를 배포 기록으로 보관합니다. 공개 배포와 운영 전환은 소유자 승인 후 진행합니다.

## 데이터 정책안 — 미적용

이름·언어·익명 사용자 ID·멤버십과 메시지·공지·일정·읽음/확인 시간을 사용합니다. 번역 원문은 MyMemory에 전송되므로 [제공자 약관](https://mymemory.translated.net/terms-and-conditions)을 사전에 안내해야 합니다. QR/공유 링크 보유자는 원문을 읽을 수 있고 링크는 회수되지 않습니다. 행사 QR도 링크 보유자 참가 방식이므로 제한 행사에는 추가 초대 승인/만료 정책이 필요합니다.

제안 보존 기간은 행사 종료 후 30일이며 운영자 내보내기·삭제 선택 및 백업 삭제 반영 기간을 함께 확정합니다. **승인받거나 자동 삭제를 설치하지 않았습니다.** 번역 카운터 정리는 채팅 보관과 별개입니다. 독립 QR 원문은 수신자의 링크에 남아 서버 삭제로 회수되지 않습니다.

익명 신원은 앱 삭제·브라우저 데이터 삭제로 잃을 수 있습니다. 운영 전 방장의 복구 가능한 계정 연결/검증 절차와 기기 이동·정보 삭제 요청 처리를 확정해야 합니다. 공지 수정 후 재확인 이력의 버전 구분은 미구현이므로 중요한 변경은 새 공지로 보냅니다.

## 서명 유지보수

영구 테스트 키와 정식 키는 분리해 소유자 비밀 저장소와 암호화한 오프라인 백업에 보관합니다. 공개 저장소·APK·로그에 개인키/비밀번호를 넣지 않습니다. Play App Signing은 정식 배포 시 별도 결정합니다. 임시 CI 키로 만든 APK의 키를 복구할 수 있다고 가정하지 않습니다. 보호 환경과 영구 키는 아직 설정되지 않았습니다.
