## 증거

- [웹·DB·실제 Auth/Realtime CI](https://github.com/jsw672768-spec/wyd-messenger/actions/runs/34361010085): `1b2927db888b597b358968d41e4e237648eaca66`에서 TypeScript, lint, 14개 테스트, Next.js 빌드, HTTP 응답, SQL 권한 검사와 격리 Supabase 시나리오 모두 통과했습니다.
- 한국어 방장·프랑스어 참가자·스페인어 외부인의 실제 익명 JWT를 사용했습니다. 유효하지 않은 JWT, 타인 메시지 수정, 역할 탈취·임의 종료를 거부했고, 중복 메시지·실시간 재연결·공지 읽음/확인·일정·집합 장소·역할 변경·행사 종료를 검사했습니다.
- 초기 Realtime 검사는 `SUBSCRIBED`와 서버 Postgres 수신 준비 사이의 간격 때문에 실패했습니다. `system` 준비 이벤트 후 누락분을 다시 읽도록 수정했습니다. `tee`가 실패를 가리지 않도록 CI는 `bash -eo pipefail`을 사용하며 최종 PASS 로그까지 확인했습니다.
- [동일 APK 설치 CI](https://github.com/jsw672768-spec/wyd-messenger/actions/runs/34324161522): Android 8/16 신규 설치·실행, 기존 서명 충돌 재현, manifest·서명·정렬·무결성 증거와 캡처를 보관합니다.
- 서명 정책 추가 뒤 버전 번호의 Groovy 구문 오류가 발견되어 명시적 속성 대입으로 수정했습니다. 관리 서명 정책을 작성한 것과 계정에 키를 등록해 배포한 것은 구분합니다.

## 번역 측정

실제 MyMemory에 합성 문장 `Meet at the main gate.`를 보낸 결과 한국어 1,202ms, 프랑스어 1,201ms였습니다. 각각 `정문에서 만나세요.`, `Rendez-vous à l'entrée principale.`를 반환했습니다. 2건의 결과이며 전체 언어 품질·행사 규모 처리량 보증이 아닙니다.

고정 지연 80ms의 모의 제공자에서 8개 조각은 순차 672ms, 병렬 168ms, 동일 요청 캐시 0.11ms였습니다. 약 4배 향상은 **통제된 모의 실험**입니다. 캐시는 인스턴스별이고 사용량 예약은 DB에서 공유합니다.

## 남은 제한

- 기존 운영 Supabase 스키마·RLS·Auth·데이터·소유권과 배포 계정은 연결되지 않았습니다. 운영 마이그레이션·데이터 삭제는 실행하지 않았습니다.
- 실제 Galaxy 오류 원인, 카메라·공유·키보드·WebView 및 실제 두 기기 전체 흐름은 미검증입니다.
- 브라우저 시각 QA는 내부 미리보기의 `ERR_BLOCKED_BY_CLIENT`로 막혔으며 우회하지 않았습니다. 빌드된 Worker의 홈·메시지·행사·일정·관리·방 HTML 검사와 구분합니다.
- 행사 규모 부하, 긴급 전달 보장, 푸시, 오프라인 전송, 모든 메뉴 10개 언어화, 방장 계정 복구, 과거 채팅 페이지 이동은 미완료입니다.
- 공지 수정 시 확인 이력 버전 분리가 없습니다. 재확인이 필요하면 **새 공지로 발송**해야 합니다.
- 운영 로그 보관·알림·백업 훈련, 관리 테스트/정식 서명키, 공개 HTTPS 주소와 도메인 검증은 미설정입니다.
